# Security

This is an unpublished 0.1.0 development candidate. It is an application hook guardrail, not an OS/network enforcement boundary. Read [the security model](docs/privacy-security.md) before evaluating it.

A private vulnerability-reporting channel will be configured after repository ownership is confirmed. Until then, report privately to the project owner through your existing trusted channel. Do not post credentials, customer prompts, transcripts or sensitive policy values in public issues. No email address or reporting guarantee is invented here.

Include the version, operating system, Agent product/version, a synthetic reproduction, expected/actual behavior and redacted logs. Check hook loading and host failure handling independently from detector behavior. Never test with production secrets.
