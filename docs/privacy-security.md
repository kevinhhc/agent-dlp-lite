# 隐私与威胁边界

检测和确认在本机运行，没有外网客户端、远程 API、遥测或常驻后台服务。告警确认期间临时监听 127.0.0.1，并打开系统默认浏览器；页面不加载外部资源。检测不会执行被检查命令，不上传待检文本，不自动打开 transcript_path 或普通敏感文件路径。文件内容只在有界脚本检查中按需读取。

v0.2 默认记录执行前告警的最终放行/拒绝，每次写入只保留最近 100 条，删除更早记录，不生成历史备份。普通无告警放行、scan 和 PostToolUse 不写入。记录包含规则、最终决定、决定来源、版本、策略指纹、脱敏且截断的上下文和原因；不保存完整原始事件、会话 ID、确认 URL 或令牌。仅按已启用正则规则脱敏，未识别的敏感内容可能仍出现在摘要中。

默认路径、全局 --history-file、兼容参数 hook --audit、查看和导出方式见[确认与记录](confirmation-history.md)。自动生成的 Hook 固定历史文件绝对路径；无需启用 audit 开关。日志不可写时拒绝当前告警操作。主动导出副本由用户管理，不参与滚动删除；本工具不会自动训练模型或修改策略。

Unix 新建策略、历史、备份及配置临时文件使用 0600；新建历史目录使用 0700。历史通过文件锁串行写入和原子替换，拒绝末端符号链接和非普通文件。已有目录权限不会自动收紧；Windows 依赖用户目录 ACL。不要把策略、历史和备份设在不可信工作目录中。管理命令可显示策略本身及备份位置，其输出不属于脱敏检测报告。

保护对象是意外通过 Agent 操作暴露的敏感数据。可修改 Hook、策略或二进制的同权限用户/Agent，或可绕开宿主工具路径的进程，不在不可绕过的保护范围内。没有管理员策略锁定、端点网络拦截或进程隔离。本地确认令牌不构成针对同用户恶意进程的权限隔离。

Prompt Hook 是否在上传前执行无法由本工具决定；宿主可能此前已同步 Prompt。PostToolUse 无法撤销已发送内容。某些宿主工具或已有执行会话的后续 stdin 没有新的执行前 Hook。退出 2 的阻断含义、错误/超时是否放行、90 秒超时是否被宿主尊重均必须实测。规则未命中不表示数据不敏感。

配置备份完整保存原配置，可能包含用户自己的凭据；它们不是脱敏历史记录，没有自动保留期，应由用户清理。发行前还需桌面验收、最终用户系统运行验证及签名。
