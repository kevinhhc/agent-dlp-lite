# 隐私与威胁边界

运行完全本地；程序没有网络客户端、远程 API、遥测或后台服务。检测不会执行被检查命令，不会上传待检文本，不自动打开 transcript_path 或普通敏感文件路径。文件内容只在有界脚本检查中按需读取。

默认不写审计日志。开启方式：`agent-dlp --policy PACK hook --agent codex --audit /absolute/path/to/audit.jsonl`。自动生成的 Hook 不包含 audit；若需要，生成配置后在管理标记之前增加该选项。日志仅有版本、事件类型、规则编号/分类/动作、检查完成状态、脚本数量和执行阶段，无原始内容、路径、会话 ID。无自动日志轮转，使用者负责大小和保留期。

Unix 新建策略、审计、备份、配置临时文件使用 0600；拒绝末端符号链接，使用非阻塞方式打开并验证普通文件。已有审计文件的宽松权限不会自动收紧。Windows 依赖用户目录 ACL。不要把可信策略和审计路径设在不可信工作目录中。管理命令可显示策略本身和备份位置，其输出不属于脱敏检测报告。

保护对象是意外通过 Agent 操作暴露的敏感数据。可修改 Hook、策略或二进制的同权限用户/Agent，或可绕开宿主工具路径的进程，不在不可绕过的保护范围内。没有管理员策略锁定、端点网络拦截或进程隔离。

Prompt Hook 是否在上传前执行无法由此工具决定；宿主可能此前已同步 Prompt。PostToolUse 无法撤销已发送内容。某些宿主工具（例如托管工具、已有执行会话的后续 stdin）没有新的执行前 Hook。退出 2 的阻断含义、失败/超时是否放行都必须实测。规则未命中不表示数据不敏感。

备份完整保存原配置，可能包含用户自己的凭据；它们不是脱敏日志。保护所在目录并人工清理旧备份。发行前还需桌面验收、各平台运行验证、签名与依赖审计。
